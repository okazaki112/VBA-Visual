功能一览

不只是画布——从拖拽到校验的完整闭环，每一块积木都带着语法模板与规则智能。

$canvas编排核心

If / For / Do / With 即容器，循环体与分支体直接在画布上嵌套编排；If-Else 双体：拖入右半区进入 Else 体。

→ 流程在画布上一目了然
$rules智能核心

变量感知与自动补全、未声明引用告警、一键声明 / 重命名联动、未使用 / 重复声明 / 循环边界检查。

→ 生成前就拦住问题
$code编辑器v1.10

code 属性编辑器全面升级：代码补全、语法高亮、查找，写条件表达式和长参数不再费劲。

→ 写参数像写代码一样快
$行级映射

实时代码预览，代码行与画布积木双向定位；支持语法高亮与代码内查找，点行即达积木。

→ 逻辑与产物永远对得上
$命令面板

Ctrl+K 统一搜索命令 / 积木 / 模板 / 画布积木，双手不离键盘完成一切；F1 打开入门指南。

→ 一切皆可搜索
$项目管理

保存 / 加载 / 最近项目 / 自动保存草稿与崩溃恢复 / 版本快照；顺手化操作：批量单次撤销、拖入自动选中。

→ 工作不丢，操作不卡

三步工作流

从空白画布到可运行的 VBA 代码，只需要三步。

STEP 01

拖拽积木

从工具箱把积木拖到画布，双击积木自动接续；拖进 If/For 容器编排循环体。

STEP 02

连线编排

连接积木定义执行顺序，属性面板配置参数；规则智能实时校验变量与语法。

STEP 03

导出运行

实时预览生成的 VBA 代码，复制进 Excel VBA 编辑器即可运行；或保存项目复用。

$

快速开始

免安装，双击即用；想参与开发也只需三条命令。

  • [1]
    下载便携版稳定版见 Latest Release；尝鲜版见 Nightly Build（随每次推送自动替换）
  • [2]
    拖拽积木编排流程双击 exe 启动，Ctrl+K 唤起命令面板，F1 查看入门指南与快捷键
  • [3]
    复制生成的代码粘贴进 Excel VBA 编辑器即可运行；系统要求 Windows 10 / 11
build-from-sourcebash
# 克隆仓库并启动开发模式
git clone https://github.com/okazaki112/VBA-Visual.git
cd VBA-Visual

pnpm install   # 安装依赖（Node ≥ 18, pnpm ≥ 8）
pnpm dev       # 启动开发服务器
pnpm build     # 构建生产版本
