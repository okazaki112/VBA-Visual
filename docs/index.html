Quick Start

三步上手

  1. 下载便携版前往 GitHub Releases 下载 exe，免安装双击即用（Windows 10 / 11）。
  2. 拖拽积木编排流程从工具箱拖出积木连接成流程，属性面板配置参数，Ctrl+K 快速调用。
  3. 复制生成的代码实时预览 VBA 代码，复制进 Excel VBA 编辑器即可运行。
# 克隆仓库并启动开发模式
git clone https://github.com/okazaki112/VBA-Visual.git
cd VBA-Visual
 
pnpm install # 安装依赖
pnpm dev # 启动开发服务器
pnpm build # 构建生产版本
