## 1. 诊断

「写代码」的主入口是 code 类属性（循环体 loopBody / 分支体 thenCode / 过程体 bodyCode / With 体）——v1.9.0 时它们仍是**裸 textarea**：无语法高亮、无缩进辅助（Tab 会跳出焦点）、无变量补全、无结构提示。写循环体的体验与「聪明」完全脱节。本轮把这一个入口做完整闭环。

## 2. 改动清单（1 个新组件 + 1 个新工具模块 + 2 处入口替换）

| 编号 | 内容 | 实现 |
|------|------|------|
| W-1 | **VbaCodeEditor 组件**（新） | overlay 高亮层方案：`pre`（复用只读预览的 vbaHighlight 生成关键字/字符串/注释着色）+ 透明 textarea 同步滚动——写侧首次获得语法高亮，零新依赖 |
| W-2 | **Enter 智能缩进** | 纯函数 nextIndentAfter：结构开启词（If..Then/For/Do/With/Select Case/Sub/Function，含 Public/Private 前缀）→+1 级；Else/ElseIf/Case→同级；End/Next/Loop/Wend 开头→−1 级（下限 0），对齐 VS Code 语义 |
| W-3 | **Tab/Shift+Tab 选区缩进** | 多行整体缩进/反缩进（幂等），单光标 Tab 插入 4 空格不跳焦点 |
| W-4 | **变量 chips 光标插入** | 已声明变量=绿 chip、未声明引用=红 chip（⚠），点击插入到光标处（selectionStart/setRangeText）——变量感知从「下拉补全」升级为「写在光标处」 |
| W-5 | **骨架速插** | If/If-Else/For/ForEach/Do While/With/Select Case 七种骨架一键插入光标处 |
| W-6 | **片段结构配对提示** | 编辑器底部实时「✓ 配对完整 / ⚠ 未闭合: For × 1」 |
| W-7 | **入口全覆盖** | 属性面板与属性对话框的全部 code 类属性替换为 VbaCodeEditor（循环体/分支体/过程体/With 体/事件体） |

纯函数层（`vbaEditor.ts`）：applySmartEnter / nextIndentAfter / insertAtCursor / indentSelection / countOpenBlocks——全部可无头单测。
