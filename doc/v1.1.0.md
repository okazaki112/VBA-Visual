## 1. 执行摘要

v1.0.0 审计发现三条主链路处于断裂状态：**导入 VBA 代码**（If/For 块体静默丢失 + 12 处失效积木引用 + 连接不落库）、**内置模板**（9 个不存在的积木 ID + 属性键名错误）、**保存体系**（两套保存格式互不兼容、无 Ctrl+S、关窗直接丢数据）。本版本全部修复，并完成 7 项体验优化。审计另识别出两个隐藏缺陷（生成器入口判定、Do Until 解析跳过），已在测试驱动下修复。

## 2. 功能开发迭代（9 项）

### F1 导入 VBA 代码链路修复 ⭐ 最高优先
- **改动点**：`vbaParser.ts` 重写多行结构解析（`vbaParser.ts:143-172`）；`EditorView.vue` restoreProjectToCanvas 连接写入 blockStore
- **实现思路**：① 修复「空数组真值判断」导致 If/For/Do/Select 块体被整段丢弃的缺陷——改为解析时用 `collectBodyText` 捕获块体原文存入 thenCode/loopBody/bodyCode，并以显式 `endIndex` 跳转（不再依赖结束词类型匹配，解决 Do Until/Select Case 以 custom-code 返回时跳到文件尾吞掉后续语句的连锁缺陷）；② 12 处失效 definitionId 全部映射到现有积木（Sub→sub-define、Set→assignment、On Error→error-handler、Range 写读→cell-write/read、工作表→sheet-activate、With→with-statement 等），无法映射的语句回退 custom-code 并保留原文；③ 导入/恢复的连接统一写入 `blockStore.addConnection`（原实现只画边不落库，代码生成退化为按位置排序、保存文件丢连线）
- **功能影响范围**：导入功能全链路；粒度取舍——Sub/If/For 结构体整体入块（块体为保真原文），语句级展开留待后续版本

### F2 内置项目模板修复
- **改动点**：`projectTemplates.ts` 全量重写 7 个模板
- **实现思路**：`block-sub`→`block-sub-define`（subName）、`block-assign`→`block-assignment`、`block-foreach`→`block-for-each-loop`（element 键名）、`block-if/else/end-if`→`block-if-else-statement`（thenCode/elseCode）、`block-range-set/get`→`block-cell-write/read`；移除 `block-end-sub`/`block-next` 死积木（生成器自动补全）；修复 `'当前元素: ' + 'item'` 静态字符串拼接为 VBA 表达式 `"当前元素: " & item`
- **功能影响范围**：首页模板列表 → 编辑器 → 代码生成全链路

### F3 首页「打开项目」落地 + 最近项目
- **改动点**：`HomeView.vue`、新模块 `projectIO.ts`
- **实现思路**：原「打开项目」选完文件不读取直接跳转（TODO 空壳）；现接通 `fs.readFile` 真正解析项目并进编辑器；localStorage 记录最近 5 个项目（名称/路径/时间），文件丢失时提示并从列表移除
- **功能影响范围**：首页交互；编辑器通过既有 consumeProjectData 通道恢复，无新流程

### F4 保存体系加固
- **改动点**：`projectIO.ts`（新）、`EditorView.vue`、`TitleBar.vue`
- **实现思路**：① 三处保存入口统一走 `buildProjectData + saveProjectToFile`（标题栏旧格式缺 graphData，保存的文件加载后画布空白——已消除，旧格式文件仍可加载，向后兼容）；② 注册 Ctrl+S（帮助文档宣传但实际不存在的键位）；③ 关窗与路由离开拦截未保存内容（关窗三选：保存并关闭/直接关闭/取消）；④ electronAPI 缺失或写盘失败从静默返回改为明确报错
- **功能影响范围**：保存/加载/关闭全链路

### F5 自动保存与崩溃恢复
- **改动点**：新模块 `autosave.ts`、`EditorView.vue`
- **实现思路**：画布变更防抖 10s 写入 localStorage 草稿；进入编辑器检测到草稿弹「恢复上次会话」（显示时间与积木数）；以「保存基线」去重——内容与最近一次手动保存一致时不生成草稿，避免已保存项目反复弹恢复提示
- **功能影响范围**：新增能力，不影响手动保存/版本快照

### F6 撤销/重做纯净修复
- **改动点**：`EditorView.vue` History 插件配置（1 处）
- **实现思路**：`beforeAddCommand` 过滤 `attrs/ports/tools/zIndex` 四类变更——悬停高亮、端口透明度、编号徽章、边工具、toFront 等样式操作不再进入撤销栈，Ctrl+Z 只撤用户内容操作
- **功能影响范围**：撤销/重做行为；节点创建/删除/属性/位置变更仍可撤销（data/position/add/remove 不在过滤列）

### F7 连线校验与环检测
- **改动点**：`EditorView.vue` validateConnection + edge:connected
- **实现思路**：原校验只检查磁铁存在，可建重复边/反向边/自环；现拦截自环、重复连线、反向连线（重连当前边自身除外）；连线成环时沿连线方向 BFS 检测并给出「循环内积木不会出现在生成代码」警告（不阻断，保留用户自由度）
- **功能影响范围**：画布连线交互

### F8 「编辑代码」陷阱修复
- **改动点**：`PropertyPanel.vue`、`EditorView.vue`
- **实现思路**：`_customCode` 一旦写入永久覆盖属性模板且无处清除；现属性面板与编辑弹窗显示「已自定义」徽标 + 「恢复模板」按钮（清除 `_customCode` 后恢复属性驱动生成）
- **功能影响范围**：属性面板、代码编辑弹窗

### F9 死代码与冗余清理
- **改动点**：删除 `HelloWorld.vue` + 3 个无引用资源、`customNode.ts` 重复主题实现、`codeGenerator.ts` 无调用导出（findEntryNodes/formatVBACode/validateVBACode）、`vbaParser.ts` 无调用 validateVBACode、`vbaHighlight.ts` 无调用 getVBASyntaxStyles、`historyStore` 无调用 undo/redo 系列、`canvasStore` 只写不读的 connections、`themeStore` toggleTheme、`blockStore` reorderBlocksByPosition、`types/index.ts` 重复声明
- **实现思路**：删除前逐一 grep 引用确认零调用方；`block-end-sub` 积木（拖入即生成非法 VBA）移出定义库；`monaco-editor` 依赖 0 引用，`pnpm remove` 移除并更新 lockfile
- **功能影响范围**：纯删除，运行行为不变；安装体积减小

## 3. 用户便捷性体验优化（7 项）

### U1 节点右键上下文菜单
- **优化位置**：`EditorView.vue` 画布事件 + 右键菜单组件（原生 DOM）
- **调整方案**：右键积木弹出菜单（编辑属性/复制/粘贴/断开所有连线/删除）；空白处右键拖拽框选保留原行为；全局点击/菜单项点击后自动收起
- **用户实际收益**：核心操作零记忆负担可发现；原有框选不受影响

### U2 选中积木不再抢页签
- **优化位置**：`EditorView.vue` node:selected
- **调整方案**：移除单击强制 `activeTab='code'`，保持当前页签
- **用户实际收益**：属性编辑不再被打断丢焦点；业务输入输出不变

### U3 执行顺序手动调整
- **优化位置**：`PropertyPanel.vue` 执行顺序区 + `EditorView.vue` onMoveUp/Down
- **调整方案**：接通既有但从未被调用的 `moveBlockUp/moveBlockDown`，加上移/下移按钮（边界禁用态）；连线模式下顺序仍由自动排序接管（面板徽章已有提示）
- **用户实际收益**：无连线场景代码顺序可控；激活存量能力而非新造

### U4 代码预览体验
- **优化位置**：`CodePreview.vue`、`EditorView.vue` onCodeLineClick
- **调整方案**：行号与代码改为同行渲染（单一滚动容器，天然同步，替代原两个独立容器错位方案）；点击代码行仅高亮+选中，移除 toFront/centerCell 的画布乱跳；新增「定位积木」按钮显式平移画布
- **用户实际收益**：长代码阅读不错位；画布视图稳定；定位能力保留且可控

### U5 编辑性能优化
- **优化位置**：`PropertyPanel.vue`、`CodePreview.vue`
- **调整方案**：属性输入 300ms 防抖合并提交（pending 记录目标积木 ID，切换选中不误写新积木）；行→积木映射由每行渲染线性扫描改为 computed 预计算 Map
- **用户实际收益**：大项目打字不卡；最终生成结果完全一致

### U6 工具箱与导入对话框易用性
- **优化位置**：`BlockToolbox.vue`、`ImportCodeDialog.vue`
- **调整方案**：搜索同时过滤收藏区（分类计数本就随过滤变化）；导入对话框关闭保留草稿（误关不再丢失已粘代码），新增显式「清空」按钮；解析 300ms 防抖
- **用户实际收益**：找积木更快；长代码粘贴零丢失风险

### U7 信息一致性修缮
- **优化位置**：`ShortcutHelp.vue`、`CanvasToolbar.vue`、`HistoryPanel.vue`、`EditorView.vue`
- **调整方案**：快捷键帮助与实际全量对齐（Ctrl+S 已落地、补充右键菜单/右键框选/移除幻影项）；多选改为 Ctrl+点击（与文档一致且符合直觉，Selection modifiers [] → ['ctrl']）；缩放显示改为 20–400% 可输入控件（新增 zoom-set 动作）；历史条目「当前」徽章改「最新」+ 列表顶部操作提示
- **用户实际收益**：所见文档即所得；行为符合直觉；小数缩放可控

## 6. 已知事项与后续建议

1. 生成代码中 code 类属性的行存在双重缩进（4+8 空格），VBA 语法有效但观感冗余——v1.0.0 既有表现层行为，本轮未动，建议 v1.2.0 调整 `codeGenerator.ts` codeIndent 逻辑并同步回归全部模板
2. 导入粒度：Sub/If/For 结构体整体入块（保真文本），如需语句级展开可基于本轮 collectBodyText 产物做二次拆分
3. 无容器积木定义（nestingType 全为 leaf），容器嵌套链路仍处休眠——与「不重构核心」边界一致，维持现状
4. `EditorView.vue` 现约 2300 行（R7 评审触发器）：内聚说明——单视图承载画布编排/保存/导入/右键/自动保存的编排层职责，本轮以 projectIO/autosave 拆出两个纯逻辑模块减压；下一步建议将右键菜单、保存加载编排、排序逻辑拆为 composables（已具备清晰边界）
5. 建议补充 vitest 将本次 25 条断言纳入 CI 常驻回归
