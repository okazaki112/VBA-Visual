## 1. 执行摘要

以「不接 AI 也能聪明」为目标，本轮把 v1.2.0 建立的规则智能底座（变量扫描/静态校验）升级为**闭环**：错误从「知道行号」到「定位到容器体内的具体子积木」（F-1 行映射重构，结清 v1.2.0 已知事项#1）；手修动作从「逐块手改」到「一键重命名联动/一键声明/一键 Option Explicit」；输入从「自由文本」到「即时校验+速填+防呆」；新增变量总览面板与变量焦点高亮让数据自己说话。全程零外部依赖、零模型调用。

## 2. 迭代点明细（14/14）

### 组一 · 反馈闭环
| 编号 | 内容 | 关键实现 |
|------|------|----------|
| F-1 | 子积木行级映射 | 生成器重构为返回 `{ code, spans }`：子积木经 `{{#children}}` 槽位行定位换算绝对行号，mappings 含容器体内子积木（自 span 在前/子 span 在后，行查找深层胜出）；错误行/点击行现在精确到子积木 |
| F-2 | 未使用变量 | occurrences 反查计数（排除自身声明块上的出现），零引用变量入面板「智能检查」区 |
| F-3 | 重复声明 | collectVariableDeclarations 全量收集（不去重），同名多块声明检出（大小写不敏感） |
| F-4 | 循环边界启发式 | 数字 start/end/step 方向矛盾（正向 step 但 start>end 等）→ 警告「循环体不会执行」 |
| F-5 | 空容器体画布提示 | 既无子积木又无备用文本的容器显示琥珀色底（updateContainerBodyStyles 随每次生成刷新） |

### 组二 · 重构智能
| 编号 | 内容 | 关键实现 |
|------|------|----------|
| R-1 | 重命名联动 | 修改变量声明名 → 确认框显示影响块数 → replaceIdentifierOccurrences 全画布词边界替换（跳过字符串/点号属性/函数调用/关键字；排除自身声明块）→ 画布节点数据同步；取消则回写旧值 |
| R-2 | 未声明变量一键声明 | 警告条每项带「声明」按钮 → 自动创建变量声明积木落位引用块左上方（同容器自动嵌入）→ 存在同层入边时自动插入上游（断边重建两侧） |
| R-3 | Option Explicit 一键补齐 | 画布有变量且无 Option 声明时提示 → 一键创建于画布顶部 |

## 4. 兼容性说明

- 项目文件格式未变（parentId 模型沿用 v1.2.0）；vbaParser/codeGenerator 对外接口不变
- mappings 数量增加（含子积木），行查找语义为「更深层的积木优先」——v1.1.0/v1.2.0 既有功能（行点击/错误高亮）不回归（25+23 断言验证）
- 零新增依赖；重命名/一键声明均为用户显式触发的动作，不改变既有自动化行为

## 5. 已知事项与后续建议

1. 变量作用域为「画布全局」近似（无块级作用域分析）——未声明/未使用判定在跨 Sub 场景可能过宽，VBA 模块级变量本就全局，当前近似合理
2. R-2 一键声明的变量类型固定 Variant，后续可在警告条提供类型选择
3. v1.1.0/v1.2.0/v1.3.0 三个 feature 分支线性叠加，强烈建议验收后按序合并 main
4. C 线 AI 方案持续保留；若引入，B 线的校验错误输出即是 AI 修错（C3）的现成输入
5. 行为测试建议迁入 vitest 常驻化
