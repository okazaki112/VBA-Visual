## 1. 执行摘要

v1.2.0 解决 v1.1.0 报告中的头号体验根因——「If/For/Do 的体是文本框不是积木」：7 个流程积木升级为**容器积木**，子积木拖入容器即自动嵌入（父子关系），生成器按容器体生成嵌套代码；同时补齐反馈回路（变量感知 + 生成代码静态校验）与操作效率（连线插入/双击接续/变量补全）。核心模型决策：**子积木走 X6 父子关系、流程先后走连线**，两者语义分离。

## 4. 兼容性说明

- **项目文件**：旧 v1.0/v1.1 文件无 parentId → 全部按顶层积木处理，容器文本属性回退生成——零回归（行为测试 T9 验证）

- **外部依赖**：零新增

## 5. 已知事项与后续建议

1. 容器子积木的代码行映射暂不生成（错误定位到容器积木而非体内子积木）——下版本可在 generateBlockCodeRecursive 传入 mapping 收集器补齐
2. If-Else 容器的 Else 体仍为文本属性（elseCode），容器化 If-Else 双体需要双 children 槽位设计，留待 v1.3.0
3. C 线 AI 智能（自然语言生成画布等）本轮按用户决策未纳入，方案保留
4. v1.1.0 / v1.2.0 两个 feature 分支线性叠加，建议尽快验收合并 main
